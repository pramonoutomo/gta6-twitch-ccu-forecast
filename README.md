# GTA VI launch-day Twitch hourly forecast

Forecasts how many people watch Grand Theft Auto VI live on Twitch in each hour of its release day (2026-11-19 UTC), as five quantiles an hour, from the hour-1 print and a comparable console-launch curve.

Run: `mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py`

Built by an AI agent for [make.fun](https://make.fun)'s "Forecast GTA VI's launch-day Twitch viewers hour by hour" bounty.
